# Kondisi dan Perulangan

## Kondisi

Gunakan `kalau` dengan operator perbandingan yang tersedia.

```text
kalau umur sudah 17 tahun
    tampilkan "Boleh masuk"
kalau tidak
    tampilkan "Belum boleh masuk"
```

Operator v0.1 mencakup bentuk `sudah`, `belum`, `sama dengan`, `lebih besar dari`, dan `lebih kecil dari`.

## Perulangan

Iterasi collection menggunakan bentuk eksplisit:

```text
untuk setiap teman di daftar teman
    tampilkan teman
```

Loop kondisi menggunakan:

```text
selama kondisi
    tampilkan "jalan"
```

Frasa percakapan yang belum memiliki grammar tidak boleh dipakai dengan harapan One akan memahami maksudnya.
